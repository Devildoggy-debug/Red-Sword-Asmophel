# Red-Sword-Asmophel
This is the project for the second week of Half Life where we have to make a CAD file. The main reason I made it, is cause its just cool as hell
I decided to make my own project this week,Its a bifurcated sword with an additional dagger added on for more stability (and it looks cooler)
There are a pair of swords that combine into one bigger sword, this is possible due to the unique carving made on both blades.The design was also derived from a bigger sword which I split into two halves.This is the sword in its attached form
